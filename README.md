# PRIMO: interactive product demo

A demo site for a fictional hydration drink, built with AI. Three.js renders a live 3D bottle that you scroll through: a slanted-logo hero, a dive into the liquid, a drinking sequence, and life-scene flavour chapters that re-theme the page. Shop, cart, about and feedback pages are included.

- Static site with no build step; open `index.html` through any web server.
- Libraries are vendored in `vendor/` (three.js 0.170.0, GSAP 3.12.5, Lenis 1.1.13) and fonts in `fonts/` (Inter and Space Grotesk, SIL OFL).
- Photos come from Unsplash (Unsplash License); credits are in the footer.

PRIMO is a fictional brand. Checkout and forms are demos: nothing is charged or sent.
